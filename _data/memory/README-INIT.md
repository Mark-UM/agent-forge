# Memory 目录说明

> 此目录用于存放 Mark 的记忆文件（MEMORY.md 及各类 user-*.md）。
> 个人画像的源文件位于 `markconfig/profile.md`。

## 当前状态

- 本目录仅包含 Mark（韩铭洋）的记忆文件。
- 如需调整个人画像，优先编辑 `markconfig/profile.md`，然后同步到本目录下的结构化记忆文件。

## 文件命名规范

- `MEMORY.md` — 核心记忆汇总
- `user-profile.md` — 基础身份画像
- `user-tech-stack.md` — 技术栈
- `user-personality.md` — 性格与偏好
- `user-career.md` — 职业规划
- `user-real-life.md` — 现实生活信息
- `user-reply-preferences.md` — 回复风格偏好
- `always-*.md` — 行为规则（如 always-show-thinking.md）

## 安全提示

- 请勿在此目录中存放 API Key 等敏感信息。
- 所有敏感信息请优先维护在 `markconfig/secrets.json` 中。
