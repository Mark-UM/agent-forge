# /prompt Command

Manage the dynamic prompt system: query status, view stats, history, and re-compose.

## Usage

```
/prompt status           # Show current prompt version + composition
/prompt stats            # Show A/B testing statistics
/prompt history [N]      # Show last N experiments (default 10)
/prompt recompose        # Recompose AGENTS_COMPOSED.md
/prompt version          # Show current version snapshot
/prompt log <args>       # Log a new experiment (internal use)
```

## Subcommands

### status
Show the current composition:
- Prompt version
- Profile (default/terse/detailed/socratic)
- Task type loaded (or none)
- Contexts loaded
- Examples loaded
- Sources list

Reads from `_runtime/prompt/version.json` (auto-generated by composer.py).

### stats
Render A/B testing statistics as a Markdown table.

Calls:
```
python -m modules.prompt.experiments --stats
```

Output includes:
- Total experiments
- Overall average review score
- Satisfaction rate
- Failure count (score < 7)
- Breakdown by task type (count, avg, min, max)
- Breakdown by profile (count, avg)

### history [N]
Show recent N experiments (default 10).

Calls:
```
python -m modules.prompt.experiments --recent 10
```

Output: Markdown table with Time / Task / Profile / Score / Satisfied / Description.

### recompose
Regenerate `AGENTS_COMPOSED.md` from current `.opencode/prompts/*` files.

Calls:
```
python -m modules.prompt.composer --pre-session
```

Useful after editing prompt files mid-session.

### version
Show the current version snapshot (JSON):
- Version
- Snapshot timestamp
- Sources loaded
- Profile
- Task

Reads from `_runtime/prompt/version.json`.

## Examples

```
/prompt status           # → current task/profile/contexts
/prompt stats            # → Markdown table of experiment stats
/prompt history 20       # → last 20 experiments
/prompt recompose        # → regenerate AGENTS_COMPOSED.md
/prompt version          # → JSON version snapshot
```

## When to use

- **After `/review`**: check `/prompt stats` to see how scores trend
- **After editing prompts**: `/prompt recompose` to regenerate the composed file
- **Mid-session**: `/prompt status` to verify which prompts are active
- **Debugging prompt quality**: `/prompt history` to compare recent experiments

## Integration with /review

After `/review` completes, the review pipeline automatically logs an experiment
via `modules/prompt/experiments.py --log`. This populates the stats seen in
`/prompt stats`.

## Data files

- `_runtime/prompt/composition_log.jsonl` — every composition (P0)
- `_runtime/prompt/experiments.jsonl` — A/B experiment records (P2)
- `_runtime/prompt/version.json` — current version snapshot (P0)
