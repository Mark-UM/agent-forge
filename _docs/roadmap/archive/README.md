# Archived Planning Material

Everything in this directory is historical, completed, superseded, or
exploratory. It is retained for decision context only.

Rules for use:

- Do not treat old file counts, paths, model descriptions, benchmarks, test
  totals, or acceptance statements as current facts.
- Verify any reusable idea against `README.md`, `ONBOARDING.md`,
  `_docs/ARCHITECTURE.md`, code, configuration, and manifests.
- New future work belongs in `../ROADMAP.md`; do not add another active roadmap
  here.
- Search v4 documents describe the evolution of the Search subsystem. The
  vendored MindSearch source tree referenced by some documents is not part of
  the maintained repository.

Archive groups:

- `v1.5-prompt-system/` — dynamic Prompt composition design and acceptance.
- `search-v4/` — Search v4 planning, acceptance, and MindSearch-inspired design.
- `v1.6-*`, `v1.7-*`, `v1.8-*` — historical stabilization, quality, and local
  automation plans.
- `v2.0-*`, `v2.5-*` — speculative Multi-Agent and self-evolution proposals.
