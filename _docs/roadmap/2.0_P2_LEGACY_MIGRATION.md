## 3. 移植时发现的主线入口故障

- Search CLI 的 main 指向不存在的 legacy_search._cli，修成现存的 main。
- Search 健康输出把新版 provider 状态字典当字符串 join，现按名称和状态格式化。
- Vision clipboard 模块导入即读取用户剪贴板，造成 Registry 健康检查副作用与失败；现仅在明确调用 CLI 时读取，并提供无图像也可使用的 --help。
- 以上入口均有先失败后通过的子进程回归测试；Registry health --json 当前为 17 healthy、0 unhealthy。
